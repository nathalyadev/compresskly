# CompressKly Front

Interface web do CompressKly (Next.js + React + TypeScript + Tailwind).

## Desenvolvimento

```bash
cp .env.example .env.local
npm install
npm run dev
```

Configure `NEXT_PUBLIC_API_URL` apontando para a API (padrão `http://localhost:5080`).

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```
